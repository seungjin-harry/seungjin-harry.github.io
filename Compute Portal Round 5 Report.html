Compute Portal — First Full Deploy Lifecycle

At the team's request, one real service was taken through its whole life with cpctl on 14 November: dry-run, deploy, observe, redeploy, stop and start, delete, and a billing check. Deploying is fast and clean. The gaps are in what the CLI tells a script or an agent afterwards. Every claim links to an exhibit with the command and the recorded output.

5What it means for agents

An agent runs cpctl exactly the way our script did: no terminal, output captured, decisions made from exit codes and JSON. Seen that way, each step of the lifecycle either gives the agent a reliable signal or it doesn't.

Agent stepSignal the agent relies onToday
Estimate and get approvalDry-run JSON: can_deploy, costReliable stable 3 of 3; price gap tracked separately
DeployExit 0 and a URLReliable
Check health--json metrics, --json listPartly list is JSON; metrics is not
Re-run safelyClear outcome for a repeated deployAmbiguous
Clean upExit code of deleteMisleading exit 0 without deleting
Agents should always pass --yes to destructive commands. Our guidance in llms.txt can say so too. The CLI still has to return an error when it refuses, because sooner or later an agent will forget the flag.

Delete reports success but deletes nothing

S2CP-CLI-014 (new)

TestRun delete with its output captured to a log, as an agent or CI job would. Poll the URL for 3 minutes, then check list and ps.

$ cpctl delete qa-nginx-11140950
Delete qa-nginx-11140950? This cannot be undone. Pass --force or --yes to confirm.
exit=0  (0 s)
  -> still not 'not200' after 180s (last HTTP 200)

$ cpctl list
│ qa-nginx-11140950 │ nginx:alpine │ running │ eu-west │ https://qa-nginx-11140950-72eab8.cpctl.app │

$ cpctl ps
│ qa-nginx-11140950 │ running │      │ eu-west │ -   │ 1   │ 1Gi    │

ResultThe CLI correctly refused to delete without confirmation, but returned exit 0. A caller that checks the exit code concludes the service is gone. The tester deleted it afterwards with cpctl delete qa-nginx-11140950 --yes.

Reproducecpctl delete <name> > out.txt 2>&1; echo "exit=$?"; cpctl list
